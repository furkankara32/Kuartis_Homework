## Kuartis Embedded Software Homework

This repository contains the implementation of the Embedded Software Homework for the Kuartis .

## System Overview

BNO085 -> SPI -> STM32F767ZI -> NMEA 0183 -> UART -> ROS2

## Repository Structure

- `embedded/` - STM32F767ZI embedded software
- `ros2/` - ROS2 C++ driver
- `docs/` - documentations
- `presentation/` - Final presentation materials
